## HCD.12:5 - Archetypal Grounding {#archetypal-grounding}

### HCD.12:5.1 - Transfer requires a positive proposal and a changed resource answer {#transfer-requires-a-positive-proposal-and-a-changed-resource}

Learner-L17 and the following observations are fictional. They illustrate the Method and provide no data about Engineer-E27 or actual programme participants.

Earlier qualified observations show L17 checking configuration evidence and explaining a supported continuation in two fresh cases without a teacher's configuration cue. In those cases, L17 rejected a report about FW7 when HW3/FW8 was required. Calculation and the 23-hour C continuation were also supported. Those familiar contributions are not themselves new transfer evidence. The earlier observations do not yet demonstrate adaptation to changed capacity.

The new case has a report that actually supports HW3/FW8/SCHED2 and confirms the required checks. Preparation takes one hour per homogeneous batch of up to four; required checks take two hours per change. Twelve changes arrive per week. At 24 available hours, ten changes require 23 hours, while twelve require 27. The release manager may authorize a bounded ten-change use and retains responsibility for the growing queue and release decision.

For this constructed comparison, L17's task history stipulates that the standalone evidence-use question—a complete report offered without a preceding mismatch problem—has not been rehearsed. That changed question must now lead to a justified positive proposal; repeating the earlier FW7 refusal would be wrong. The task does not ask for a pattern name. Reports, calculator and ordinary source and tool access are available. The source and assistant traces place L17's first recognition and proposal before any teacher or AI cue supplies the decisive condition.

| Observation | What it supports | What it does not support |
| --- | --- | --- |
| Before any PatternID or configuration cue, L17 checks the complete report and proposes ten changes in three homogeneous batches, requiring 23 hours, with two new changes left in the weekly queue. | Transfer of configuration-evidence use and a bounded positive proposal in this unfamiliar case. | Release authority, elimination of the queue or general transfer across all engineering work. |
| The assessor changes only available time from 24 to 22 hours. L17 initially keeps the ten-change promise. | A demonstrated adaptation failure under the changed resource condition. | A conclusion that the earlier configuration or calculation contribution has disappeared. |
| After feedback asking L17 to check the changed time constraint, L17 calculates that nine changes require 18 + 3 = 21 hours, while ten still require 23, and revises the proposal. | Correct adaptation with feedback. | Independent resource adaptation on the first changed-condition attempt. |

The useful local return is complete: preserve the supported calculation and configuration evidence and identify capacity adaptation as unproven independently. If stronger reliance on independent capacity adaptation is pursued, arrange a fresh uncued variation before making that claim. HCD.14 can use this result immediately to propose a small practice revision; a retention test is not a prerequisite.

An assessor who accepts “the evidence is never sufficient, so I refuse” would miss the positive-action criterion in the first row. An assessor who scores only the corrected final answer would miss the independent adaptation failure in the second.

### HCD.12:5.2 - The named Method supplies what the test meant to observe {#the-named-method-supplies-what-the-test-meant-to-observe}

In another constructed task, a person makes no relevant first move but produces a correct comparison immediately after the assessor says which Method to use. The result supports application after that cue. It leaves uncued recognition unresolved or failed according to the original task criterion; it does not establish global capability loss.

If the practical question is application with a routinely supplied Method, that result may already be useful. If the work requires the person to select the Method, the next task must preserve that selection problem.

## HCD.12:6 - Bias-Annotation {#bias-annotation}

Unfamiliarity is person-relative. A task familiar to the assessor may be novel to the learner, and a nominally new task may have been rehearsed elsewhere. Retain relevant exposure instead of treating cohort membership as proof.

Do not make “caution” a universal success criterion. A person who refuses every case may avoid one error while failing the required useful action. Also check that apparent adaptation is not merely the assessor naming the changed condition.

## HCD.12:8 - Common Anti-Patterns and How to Avoid Them {#common-anti-patterns-and-how-to-avoid-them}

| Anti-pattern | Better move |
| --- | --- |
| “The names changed, so this is transfer.” | Show which unfamiliar condition could make the old response wrong. |
| “Every test contains a hidden error.” | Include complete evidence that requires a justified positive action. |
| “I named the Method, and the person selected it.” | Report application after a cue; preserve selection as a separate question. |
| “The changed case failed, so the old capability is gone.” | Preserve the old envelope and locate the failed adaptation or missing prerequisite. |
| “Reading a new source proves retention.” | Report learning with that source and its supplied contribution. |

## HCD.12:10 - Rationale {#rationale}

Transfer is a relation between demonstrated contributions and changed conditions, not a property conferred by finishing a course. Preserving the prior claim makes both success and failure informative. Keeping recognition, access, adaptation and result separable shows which new observation could change the conclusion without pretending that every failed answer reveals its cause.

## HCD.12:11 - SoTA-Echoing {#sota-echoing}

**Working question:** how can an unfamiliar task distinguish useful transfer from repeated execution, while allowing learning resources when the intended work uses them?

**Selected line — adopt and adapt.** The [workplace-instruction review by Kraiger and Ford](https://www.annualreviews.org/content/journals/10.1146/annurev-orgpsych-012420-060109) distinguishes instructional activity, learning and later transfer. HCD.12 turns that distinction into the prior-claim and changed-condition comparison in §4.1–§4.4, with the action-versus-refusal test in §5.1.

**Serious alternatives:** repeat the same exercise under new labels, or remove all resources to avoid assistance. Repetition is useful for practising execution but leaves consequential adaptation untested. A resource-free test is useful for an independently required core but can omit the ability to learn with a source. At comparable task time, a decision-bearing variation gives a more relevant answer than cosmetic novelty; source access remains a declared condition rather than a hidden advantage.

The historical [Schwartz and Martin preparation-for-future-learning study](https://aaalab.stanford.edu/assets/papers/2004/Inventing_to_prepare_for_future_learning.pdf) showed why assessment with a later learning resource can distinguish outcomes missed by a resource-free test in ninth-grade statistics. HCD.12 adapts that design distinction in §4.5. It does not use that study as evidence that a particular adult programme accelerates learning.

This selected line requires a task whose criteria discriminate the contribution, not an automatic claim of transfer. Reopen the comparison if prior exposure defeats the novelty claim, the variant changes an unacknowledged prerequisite, or source access and feedback cannot be separated from the claimed independent contribution.
